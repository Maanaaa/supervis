## Structure du Dépôt

Le projet est strictement compartimenté pour garantir une maintenance limpide :

```
.
├── AGENT.md                 # Directives de session et boussole pour l'agent IA
├── README.md                # Vue d'ensemble du dépôt
├── docs/                    # Dossier de documentation & conception
│   ├── base_de_connaissance.md  # Portail global de cadrage, modèles et flux
│   ├── adr/                     # Architecture Decision Records (ADR-0001 à 0005)
│   └── assets/                  # Captures d'écran, diagrammes, problématique
└── app/                     # Code source de l'application (Node.js / Express / Socket.io / Mongo)
```
